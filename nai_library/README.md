# NAI 资源库

独立项目。**只管看图和整理，不参与出图**——出图在另一个项目 `nai_repro`。

## 启动

双击 `start_library.bat`，或：

```bash
python lib_server.py --open     # 默认 http://127.0.0.1:8780/
```

不需要 Token，不联网，纯本地只读（除了整理操作会改批次目录）。

## 它和 NAI 复现工具的关系

```
D:\AI project\
  nai_repro\          出图工具（生成、复现、LLM 分析）
    out\batches\...   产出的批次数据
  nai_library\        本资源库（浏览、查参、整理）  ← 只读上面那个 out/
    lib_config.json   指向 nai_repro 的路径
```

**两个独立服务、独立端口、互不干扰**：
- NAI 复现工具 `http://127.0.0.1:8770/`
- 资源库 `http://127.0.0.1:8780/`

资源库复用 `nai_repro` 里的 `repro.py` / `llm_analyze.py` 做元数据解析
（格式是那边定义的，不重复实现），但**不修改**它的任何代码。

## 界面

```
┌─ NAI 资源库 ──────────────────────────────────────────────────┐
│ [批次▼][排序▼][搜索___]  319/319  [批次管理][导出选中][模糊]   │
├──────────────────────────┬────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐     │ 信息 │ 提示词 │ LLM 分析          │
│ │ 图 │ │ 图 │ │ 图 │     ├────────────────────────────────────┤
│ └────┘ └────┘ └────┘     │ 大图                               │
│ ┌────┐ ┌────┐ ┌────┐     │ 来源 / seed / 步数 / CFG / 尺寸     │
│ │ 图 │ │ 图 │ │ 图 │     │ 参数核对（原始 vs 发 vs 回执）     │
│ └────┘ └────┘ └────┘     │ 文件路径 + 打开所在目录            │
│                          │                                    │
└──────────────────────────┴────────────────────────────────────┘
```

点左边任意一张图，右边出详情。右侧三个标签页切换：

| 标签 | 内容 |
|---|---|
| **信息** | 参数、来源模型、条件检测警告、参数核对、文件路径 |
| **提示词** | 基础 / 各角色 / 负面，每段可单独复制；角色显示坐标 |
| **LLM 分析** | 如果 `nai_repro` 里跑过分析，这里直接看完整报告 |

其他：

- **排序**：时间 / 作品名 / seed / 批次
- **搜索**：作品名、seed、批次名
- **模糊原图**：默认开启，鼠标悬停临时减淡（截图 / 旁人时有用）
- **导出选中**：图块右上角勾选 → 复制成图到一个扁平目录，方便直接拿出去用
- 缩略图按需生成，缓存在本项目自己的 `cache/`，不碰 `nai_repro` 的目录

## 批次管理

点顶栏「批次管理」：

- 改名 / 只看这批 / 删除
- **按作品号重命名**：把 `20261014-005018_nai5-full` 改成 `149276524 · 10-14 00:50`
  （只改时间戳式的名字，手改过的不动）
- **合并同作品的批次**：一张一张跑出来的结果会碎成几十个批次，这个把同一作品的并成一个

> 实测：30 个批次 → 10 个，319 张图三种方式核对一张没少。

## 配置

`lib_config.json`：

```json
{
  "nai_dir": "D:\\AI project\\nai_repro",
  "port": 8780,
  "host": "127.0.0.1"
}
```

`nai_dir` 指向 NAI 复现工具所在目录即可，资源库自己去读它下面的 `out/batches/`。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 数据来源、批次数、图片数 |
| GET | `/api/library?batch=&sort=` | 图片索引 |
| GET | `/api/library/item?batch=&f=` | 单图完整信息 |
| GET | `/api/batches` | 批次列表 |
| GET | `/img?kind=thumb\|full&id=&f=&w=` | 缩略图（带缓存）/ 原图 |
| POST | `/api/batches/rename` | 批次改名 |
| POST | `/api/batches/autoname` | 按作品号批量重命名 |
| POST | `/api/batches/merge` | 合并批次（`{"auto":true}` 自动分组） |
| POST | `/api/batches/delete` | 删除批次（需 `confirm`） |
| POST | `/api/export` | 把选中的图复制到指定目录 |
| POST | `/api/reveal` | 在资源管理器中定位文件 |

访问范围被限制在 `nai_repro/out/` 与本项目 `cache/` 内，越界直接 400。
